# WheeTrometer_Teensy
Code for the Teensy 4.0 based Spectrometer.  Arduino firmware for the Teensy in the WheeTrometerTeensy folder.  Processing code for the general user interface is in the WheeTrometer_823 folder.
Information on using the files to build and use the spectrometer can be found at www.SmokyMtSci.com
